## 🛠 Features
- **Rapid Emergency Triage (ESI 1-5):** Instant categorization based on vitals and symptoms.
- **Cardiology Focus:** STEMI/NSTEMI, Acute Coronary Syndrome, Decompensated Heart Failure, Pulmonary Embolism protocols.
- **Vitals Analysis:** NEWS2 (National Early Warning Score 2) calculation with abnormal vital flagging.
- **Clinical Decision Support:** Investigation bundles, initial pharmacotherapy checklists, and ICU admission criteria.
- **Multi-lingual & Audio Alerts:** Critical triage alarms and audit trails.
